# 背包问题多项式近似算法
## 背包问题
_Problem_：给定 n 个物品：$a_1,a_2,...,a_n$，他们的大小为 $size(a_i)$，利润为 $profit(a_i)\in N^{+}$，而背包的容量为 $B\in N^{+}$，选择大小最多为 $B$ 的物品，使得利润最大。

由于背包问题是一个 NP 难问题，所以我们不期望有一个高效的多项式精确算法能够解决该问题。
>在这个问题之前，我们老师还介绍了编码与 NP 问题的一些关系

## 编码：二进制与一进制
_Definition 1_：
二进制 $|I|$：一个问题 $I$ 的输入大小（由二进制编码表示）；
一进制 $|I|_u$：一个问题 $I$ 的输入大小（由一进制编码表示）。
>Interpretation：一进制就是用 1 做计数。For example: 5=11111; 3=111

_Definition 2_：
一个问题的多项式算法在 $|I|$（二进制编码）下的运行时间是多项式；
一个问题的伪多项式算法在 $|I|_u$（一进制编码）下的运行时间是多项式。


_Definition 3_：
如果一个优化问题在 $|I|_u$（一进制编码下）是一个 $NP-hard$ 问题，那么它是一个 $strongly\;NP-hard$ 问题；
如果一个优化问题在 $|I|$（二进制编码）下是一个 $NP-hard$ 问题但是有一个伪多项式算法，那么它是一个 $weakly\;NP-hard$ 问题。

_Theorem_：
除非 $NP=P$，否则 $strongly\;NP-hard$ 问题没有伪多项式算法。

证明（反证法）：
若 $strongly\;NP-hard$ 问题 $\Pi$ 有伪多项式算法，则 $\Pi$ 在 $|I|_u$（一进制编码）下运行的时间为多项式，又因为 $\Pi$ 在 $|I|_u$ 下为 $NP-hard$ 问题，所以在 $|I|_u$ 下，$\Pi$ 有多项式时间算法，即有 $NP=P$（矛盾）。

## 背包问题的精确伪多项式算法
>与流行的背包问题解法不同，该精确算法使用利润做动态规划

令 $P=max\{profit(a_i)\}$，则 $P\leq OPT \leq nP$
又令 $S_{i,p}$ 为当利润精准等于 $p$ 时，在 ${a_1,a_2,\dots,a_i}$ 中选出的最小大小（~~容量，重量？说大小奇奇怪怪的~~）的集合（该集合可能并不存在），$A[i,p]$ 为该集合的总大小。（如果 $S_{i,p}$ 不存在，则 $A[i,p]=\infty$）

_初始化_：
对 $\forall p \in [1,nP]$，$A[1,p]$ 可以被计算；令 $A[1,p]=\infty, \;\forall p<0$。

_动态方程_：
$A[i+1,p]=min\{A[i,p],size(a_{1+i})+A[i,p-profit(a_{i+1})]\}$

_最终结果_：
如果 $A[i,p]$ 全部计算出来，则 $OPT=max\{p;A[n,p]\leq B\}$

_时间复杂度_：$O(n^2P)$
_代码_（用[采药](https://www.luogu.com.cn/problem/P1048)一题验证对否，并输出了其集合）：
```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=101,M=10000;
int n,B,size[N],profit[N],A[N][M],sum_p;
int main(){
	cin>>B>>n;
	for(int i=1;i<=n;i++)cin>>size[i]>>profit[i],sum_p+=profit[i];
	memset(A,0x3f,sizeof(A));
	for(int i=0;i<=n;i++)A[i][0]=0;
	for(int i=1;i<=n;i++){
		for(int j=1;j<profit[i];j++)A[i][j]=A[i-1][j];
		for(int j=profit[i];j<=sum_p;j++)A[i][j]=min(A[i-1][j],size[i]+A[i-1][j-profit[i]]);
	}
	int mx=0;
	for(int i=1;i<=sum_p;i++)if(A[n][i]<=B)mx=i;
	cout<<mx<<"\n";

	// === 回溯求选中的物品集合 ===
	vector<int> chosen;
	int j=mx;
	for(int i=n;i>=1;i--){
		// 物品 i 被选中的条件
		if(j>=profit[i] && A[i][j]==size[i]+A[i-1][j-profit[i]]){
			chosen.push_back(i);
			j-=profit[i];
		}
		// 否则 i 没选,j 不变
	}
	reverse(chosen.begin(),chosen.end()); // 改成编号从小到大

	cout<<"选中物品编号:";
	for(int x:chosen)cout<<" "<<x;
	cout<<"\n";
	return 0;
}
```
>该代码的时间复杂度其实是 $O(n\cdot sum\_profit)$，用 $nP$ 做时间复杂度有太多不必要的计算。上面讲的 $O(n^2P)$ 的时间复杂度是联系下文 qwq。

其中，`ExactProfitDP` 表示上一节给出的、以利润为状态维度的精确动态规划算法。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=101,M=100000;
int n,B,size[N],profit[N],orig_profit[N],A[N][M],sum_p,P=0;
double K,eps=0.1;
int main(){
	cin>>B>>n;
	for(int i=1;i<=n;i++){
		cin>>size[i]>>profit[i];
		orig_profit[i]=profit[i];   // 保存原始利润
		P=max(P,profit[i]);
	}
	K=eps*(double)P/n; //放缩因子
	for(int i=1;i<=n;i++)profit[i]=max(1,(int)((double)profit[i]/K)),sum_p+=profit[i]; //max避免 0 利润的取舍,会略微偏离上面的界
	memset(A,0x3f,sizeof(A));
	for(int i=0;i<=n;i++)A[i][0]=0;
	for(int i=1;i<=n;i++){
		for(int j=1;j<profit[i];j++)A[i][j]=A[i-1][j];
		for(int j=profit[i];j<=sum_p;j++)A[i][j]=min(A[i-1][j],size[i]+A[i-1][j-profit[i]]);
	}
	int mx_profit=0;
	for(int i=1;i<=sum_p;i++)if(A[n][i]<=B)mx_profit=i;
	cout<<mx_profit<<"\n";

	// === 回溯求选中的物品集合 ===
	vector<int> chosen;
	int j=mx_profit;
	for(int i=n;i>=1;i--){
		if(j>=profit[i] && A[i][j]==size[i]+A[i-1][j-profit[i]]){
			chosen.push_back(i);
			j-=profit[i];
		}
	}
	reverse(chosen.begin(),chosen.end());

	int real_profit=0,total_size=0;
	cout<<"选中物品编号:";
	for(int x:chosen){
		cout<<" "<<x;
		real_profit+=orig_profit[x];   // 用原始利润求真实价值
		total_size+=size[x];
	}
	cout<<"\n真实总利润: "<<real_profit<<"\n";
	cout<<"占用容量: "<<total_size<<" / "<<B<<"\n";
	return 0;
}
```

_Lemma_：
$$profit(S')\geq (1-\epsilon)\times OPT $$
_Proof_：
令 $S_{OPT}=\{o_1,o_2,\dots,o_k\}$。

_obs 1_：
$$\because \forall i\in {1,2,\dots,k},profit(o_i)-K\leq K\cdot profit'(o_i)\leq profit(o_i)\\
\therefore K\cdot \sum_{i\in S_{OPT}}{profit'(o_i)}\geq OPT-kK\geq OPT-nK\geq OPT-\epsilon P$$
_obs 2_：

$$
\because profit(S')\geq K\cdot profit'(S')\geq K\cdot \sum_{i\in S_{OPT}}{profit'(o_i)}\\
\therefore profit(S')\geq OPT-\epsilon \cdot P\geq OPT-\epsilon\cdot OPT=(1-\epsilon)\cdot OPT
$$
_Theorem_：
该近似算法的时间复杂度为 $O(n^3/\epsilon)=O(n^2\cdot P/K)$。

## 近似方案（approximation scheme）
_Definition_：
令 $\Pi$ 为一个优化问题，若算法 $\mathcal{A}$ 满足如下条件，则称其为多项式时间近似方案（PTAS：polynomial-time approximation scheme）：
对任意输入 $(I,\epsilon)$，算法 $\mathcal{A}$ 输出一个可行解 $s\in S_{\Pi}(I)$，且满足：
+ $\Pi$ 为极小化问题，目标函数值 $obj_{\Pi}(I,\epsilon)\leq (1+\epsilon)\cdot OPT$
+ $\Pi$ 为极大化问题，目标函数值 $obj_{\Pi}(I,\epsilon)\geq (1-\epsilon)\cdot OPT$

对于任意固定的 $\epsilon$，算法 $\mathcal{A}$ 为多项式。
特殊地，若算法 $\mathcal{A}$ 关于输入规模 $I$ 与精度倒数 $\epsilon$ 呈多项式关系，则称该算法为完全多项式时间近似方案（FPTAS：fully polynomial-time approximation scheme）。

>For example:
>+ $O(n^{\frac{1}{\epsilon}}) \leadsto $ PTAS
>+ $O(2^{\frac{1}{\epsilon}}n^2) \leadsto$ PTAS
>+ $O(\frac{n^3}{\epsilon^{2}}) \leadsto$ FPTAS

_Theorem_：
设 $p$ 为多项式，$\Pi$ 为 $NP-hard$ 极小化优化问题；且对于 $\Pi$ 的任意实例 $I$，最优化目标值满足 $OPT(I)< p(|I|_u)$：
若问题 $\Pi$ 存在完全多项式时间近似方案（FPTAS），则该问题存在伪多项式精确算法。

_Proof_：
设该 FPTAS 的运行时间为 $q(|I|,1/\epsilon)$（q 为二元多项式），其中令误差为 $\epsilon =\frac{1}{p(|I|_u)}$，$ALG$ 为该算法的结果。
$$ALG \leq (1+\epsilon)\cdot OPT \\ ALG\leq OPT+\epsilon \cdot OPT \\ ALG < OPT+\epsilon \cdot p(|I|_u)\\ ALG < OPT+1 \\ \because ALG\geq OPT \\ \therefore ALG=OPT$$
对于时间复杂度：将 $1/\epsilon=p(|I|_u)$ 带入 $q$ 为 $q(|I|,p(|I|_u))$，即为伪多项式。
>Interpretation：
>这里的 $OPT(I)< p(|I|_u)$ 也许有点难以理解，可以拿背包问题举个例子，它的最优解是不是就是最大的利润，但它的最大利润是不会超过所有物品加起来的利润的。
